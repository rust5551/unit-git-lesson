1. Свой репозиторий
- Создайте локально на компе папку с любыми кодовыми файлами
- Создайте публичный репозиторий на GitHub и запушьте туда свой локальный репозиторий

2. .gitignore
- Создать файл в папке вашего репозитория .env и написать туда любой секрет который надо знать, но он не должен попасть в репозиторий
- Создать файл .gitignore и записать в него .env файл
- Всё запушить

3. Сливание веток
- Склонировать репозиторий https://github.com/rust5551/unit-git-lesson
- Создать ветку со своей фамилией от main
- В проекте есть ветка slei-menya-po-bratski, нужно слить изменения из этой ветки в вашу
- Запушить изменения
- Перейти на main ветку в локальном репозитории

4. Конфликты
- Переключиться на ветку с вашей фамилией
- В файл repositories.txt вставить ссылку на свой репозиторий
- Создать pull request из вашей ветки в main
- Сказать мне, что сделали pr я посмотрю и дам добро сливать его в main


5. Удаление ветки
- Поскольку ваша ветка с фамилией больше не нужна – удалите её на удалённом репозитории и на локальном
